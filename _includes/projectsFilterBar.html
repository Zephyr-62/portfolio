{% comment %} Filter bar of the project listing. One dropdown per portfolio version, driven by _data/versions.yml: the categories of one version never show up in the other (e.g. "Level Design" is not a filter of the software engineering listing). Both dropdowns share the `.projFilter` class, so the listing script only has to deal with the one left in the DOM (see assets/js/portfolioVersion.js). "All Projects" is the union of every category of that version, which is also what the listing falls back to when no `filter` parameter is given. {% endcomment %}
